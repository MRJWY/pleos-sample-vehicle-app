# Pleos 펫 정원 디자인

주차하고 돌아온 사람이 처음 마주치는 장면을 설계하라. 양이 고개를 들어 사용자를 보고, 손이 갈 만한 거리에 서 있고, 사용자가 놓은 들꽃이 그 옆에 보이게 하라. 인기 생활 게임과 가상 쉼터에서는 돌봄과 공존의 리듬을 참고하고 캐릭터 실루엣, 의상, 가구, UI, 소리와 이름은 직접 설계하라. 앱 이름은 플레오마루다. 플레몽은 마을에 사는 고정 이웃 NPC로, 사용자 주민은 이름·동물 모습·옷깃 배지 선택으로 표현하라. 반려 양의 입양·성장 기록은 사용자 주민 프로필과 구분하라.

## 현재 화면에서 시작하기

1. 저장소의 `PET_GARDEN_PLAN.md`로 제품 규칙을 확인하고, 현재 체크아웃에서 `GardenScene`, `PetGardenApp`과 실제 호출 지점을 찾아라. 사용자의 로컬 수정이 있다면 그 상태를 기준으로 작업하라.
2. 실행 환경이 있으면 수정 전 개인 정원을 동일한 저장 상태에서 캡처하라. 상단 바와 시스템 영역을 제외한 앱 표시 영역을 기준으로 구도를 판단하라.
3. 그림이 축소돼 보이면 원본 픽셀 수, 장면 컨테이너 크기, 가로세로 배율, 배경과 펫을 하나로 그렸는지 차례로 확인하라. 초기 구현에서 확인된 지점은 스크롤 Column 내부의 300dp Canvas와 독립적인 x/y 배율이다. 현재 코드에도 해당하는지 확인하라.

## 정원을 화면의 주인공으로 만들기

- 차량 가로 홈은 정원을 바탕으로 하는 하나의 장면으로 구성하라. Compose에서는 앱 영역을 채우는 Box에 배경, 배치물, 캐릭터, HUD를 겹쳐라. 시스템 인셋은 조작부에 반영하고 첫 화면에서 스크롤 없이 펫의 얼굴과 발, 가장 최근에 놓은 소품이 보이게 하라.
- 원경은 대비를 낮춘 숲과 하늘, 중경은 집과 길, 근경은 펫과 배치물로 나눠라. 발밑 접지 그림자, 하나의 광원, 사물 간 겹침으로 땅 위의 위치를 읽을 수 있게 하라. 펫 뒤쪽에는 단순한 색면을 남겨 얼굴과 귀가 눈에 들어오게 하라.
- 첫 가로 시안에서 펫의 높이를 장면 높이의 약 1/4로 잡아 보고, 실제 표시 크기에서 눈과 귀의 반응이 읽히도록 조절하라. 좁은 기기에서는 주변 풍경을 잘라내거나 카메라 중심을 옮겨라. 펫과 소품은 가로세로에 같은 배율을 적용하고, 그 좌표 변환을 터치 판정에도 사용하라.
- 기본 HUD에는 펫 이름·잎사귀와 필요한 메뉴 진입점만 두어라. 소품 가격은 꾸미기에서, 거리·점수의 출처와 보상 상태는 여정에서 보여라. 개발용 시나리오와 SDK 진단은 개발 메뉴에서 접근하게 하라.

## 아트와 움직임

- 양의 옆모습에서도 알아볼 수 있는 귀·앞머리·발의 실루엣을 먼저 정하라. 털의 큰 덩어리와 얼굴의 명암, 눈과 코의 위치를 일관되게 유지하라. 편안한 숲색, 따뜻한 양털색과 나무색을 기본으로 사용하고 행동 피드백에만 밝은 강조색을 사용하라.
- 배경, 집, 양, 소품은 독립적으로 이동·교체·가림 처리할 수 있게 제작하라. 래스터 아트는 투명 여백을 정리하고 예상 최대 표시 픽셀 크기로 내보내라. 동일한 발바닥 기준점으로 캐릭터 포즈를 맞춰 전환할 때 떠 보이거나 튀는 현상을 막아라.
- 기본 자세에는 느린 호흡과 간헐적인 눈 깜빡임을 주어라. 쓰다듬으면 눈을 감고 손 쪽으로 기대고, 먹이를 주면 고개를 숙이고 씹고, 함께 쉬면 몸을 웅크리게 하라. 펫의 모습만으로 세 행동을 구분할 수 있게 하라. 정원 밖으로 이동하거나 주행 제한이 걸리면 장면 애니메이션을 멈춰라.

## 조작과 상태 연결

- 펫을 누르면 얼굴을 가리지 않는 위치에 돌봄 행동을 열어라. 터치 영역에 접근성 이름을 부여하고, 그림 속 작은 손이나 귀를 정확히 누르지 않아도 되게 하라. 조작 직후 펫의 반응을 보여주고 지급 내역은 짧게 표시하라.
- 오늘 보상을 받은 뒤에도 펫은 터치에 반응할 수 있게 하라. XP·잎사귀 지급 여부는 기존 엔진이 결정하게 하고 애니메이션 재생이 보상 지급을 다시 호출하지 않게 하라.
- 꾸미기에서는 정원을 보면서 구매 전 모습을 확인하고, 구매·배치·보관 결과가 같은 자리에 바로 반영되게 하라. 구매 실패 시 소품과 잔액을 기존 상태로 유지하라. 마을 미리보기에는 실제 유저와 구별되는 NPC 표시를 사용하라.
- 주행·미확인 상태에서는 장면·입력·열린 메뉴를 함께 가려라. 개발용 정차 모드는 시뮬레이션임을 밝히고, 테스트 주행거리·안전점수 표시는 해당 데이터가 등장하는 화면에 배치하라.

## 결과 확인하기

| 확인 장면 | 판정 기준 |
|---|---|
| 가로 홈 / 좁은 창 | 스크롤 없이 양의 표정과 배치물이 읽히고, 두 비율에서 양의 체형이 같으며, 보이는 양을 누르면 행동 메뉴가 열린다. |
| 돌봄 | 쓰다듬기·먹기·쉬기의 포즈가 다르다. 같은 날 같은 행동을 반복해도 잎사귀가 다시 늘지 않는다. |
| 꾸미기 | 들꽃 구매 전후에 바뀐 지점이 보인다. 보관·재배치 후 비용이 추가되지 않고 재실행 후 배치가 복원된다. |
| 제한 상태 | 행동 메뉴 또는 구매 확인을 연 상태에서 제한으로 전환해도 게임 입력이 남지 않는다. |

실행 화면을 원래 해상도로 확인하라. 수정 전후 같은 장소의 가로 캡처와 돌봄 반응의 짧은 연속 캡처 또는 영상을 근거로 보고하라. 빌드·실행을 수행하지 못했다면 확인한 코드와 미확인 동작을 밝혀라. 컨셉 시안과 에뮬레이터 캡처의 출처를 표시하라.
